# Video Game Blog Application

## Descrizione
L'applicazione **Video Game Blog** è un progetto personale ancora in fase di sviluppo. L'obiettivo è creare una piattaforma dove gli utenti possano esplorare, aggiungere e gestire post relativi a videogiochi. Attualmente, è possibile:

## Funzionalità Implementate
- **Visualizzazione dei Post**: Gli utenti possono esplorare l'elenco di post già creati.
- **Aggiunta di Nuovi Post**: Possibilità di aggiungere nuovi contenuti al blog.
- **Modifica Post**: Gli utenti possono modificare i post esistenti.
- **Dettaglio Post**: Ogni post ha una pagina dedicata dove è possibile visualizzarne i dettagli.
- **Filtri**: I post possono essere filtrati per categoria o per parole presenti nel titolo o nella breve descrizione.

## Tecnologie Utilizzate

### Backend
- **Node.js**
- **Prisma**: Utilizzato come ORM per interagire con il database.
- **Express**: Utilizzato per la creazione delle API REST.

### Frontend
- **Vue**
- **Gestione degli errori**: Implementata per catturare gli errori dal backend e visualizzarli all'utente.
- **Validazione**: I dati vengono validati lato frontend per migliorare l'esperienza utente.

## Funzionalità Future
L'applicazione è ancora in fase di completamento. Tra le funzionalità previste per le prossime versioni ci sono:
- **Autenticazione Utente**: Permettere agli utenti di registrarsi e accedere per creare post personalizzati.
- **Commenti ai Post**: Aggiungere la possibilità di commentare i post.
- **Like/Dislike**: Implementare un sistema di valutazione dei post con likes e dislikes.
